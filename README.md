### stuff in the open

- **[reclaim](https://github.com/nalyDzzz/reclaim)**: Windows cleanup companion. Uninstall apps and their leftovers, see what's filling your drive, clear caches, debloat. Rust + Tauri.
- **[splitwire](https://github.com/nalyDzzz/splitwire)**: per-app split tunneling for WireGuard on Windows. Pick which apps use the VPN; everything else stays on your normal connection.
- **[SilkCast](https://github.com/nalyDzzz/SilkCast)**: an IPTV player app.
- **[finance-reconcile-mcp](https://github.com/nalyDzzz/finance-reconcile-mcp)**: read-only MCP server that reconciles SimpleFIN Bridge against Firefly III.
- **[visual-parity-mcp](https://github.com/nalyDzzz/visual-parity-mcp)**: MCP server and CLI for visual QA between a live site and its local migration.
